# WastedWaffle — League Custom Skins Archive

Every version of every mod I've made: full packages — skin, voice, icons,
loading screens where they exist. Everything is free.

Posts, notes, and commissions live on Patreon:
https://www.patreon.com/c/WastedWaffle

## How to download

Open a mod's folder, open the file, and use the download button on the file
page (top right, "Download raw file"). Files marked ◆ are too large for
GitHub — they live in the MEGA archive, linked from that mod's Patreon post.

## Install

Add the .fantome file(s) to your mod manager (CSLOL / cslol-manager) and run
it with League. Skin, voice, and icons are separate files — install whichever
parts you want.

Testing note: test heavy skins in a real or bot game, not the practice tool —
the practice tool ejects you for reconnecting and makes working mods look
broken.

## Jasmine — Fall, Suspended (separate release)

A separate LeBlanc release from the Songbird line above — not a variant of
it. The Fall, Suspended dress paired with its own voice pack: Jasmine's
voice, where the Songbird release uses Song So Mi's.

- Dress: [Fall-Suspended-v1.0.13.fantome](jasmine-fall-suspended/Fall-Suspended-v1.0.13.fantome)
  in the `jasmine-fall-suspended` folder.
- Voice (current): [leblanc-jasmine-voice-v4.1-official-laugh.fantome](jasmine-fall-suspended/leblanc-jasmine-voice-v4.1-official-laugh.fantome)
  in the `jasmine-fall-suspended` folder — the official voice. The v4
  pack with one change: the laugh. All 20 laugh-group slots across
  base / skin12 / skin20 carry Jasmine's official laugh (the stitched
  arc: pffft leak, nteeh~ monotone teeth run, quietly-happy wheeze,
  nasal chuckle ending, shortened sarcasm tail); every other slot is
  byte-identical to v4. Single file, 39.9 MB (MD5:
  `80a3e5062d31371c8a5dc033b11115b3`) — single-copy packaging, since
  the game's WAD references only the plain wpk names.
  Previous builds:
  [leblanc-jasmine-voice-v6-rosetta.fantome](jasmine-fall-suspended/leblanc-jasmine-voice-v6-rosetta.fantome)
  (v6 "Rosetta", 483 lines voiced 1:1 from her archive recordings) ·
  [leblanc-jasmine-voice-v5-final.fantome](jasmine-fall-suspended/leblanc-jasmine-voice-v5-final.fantome)
  (v5, synthesized; core set voiced, champion-interaction lines silent).
